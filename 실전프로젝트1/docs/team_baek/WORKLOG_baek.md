### 2. 제공 파일 분석
**데이터 (`pii_synth_finance_dev/test.jsonl`)**
- dev: 문서 100건, 개체 548개 / test: 문서 200건, 개체 1,165개
- 실제 라벨은 7종이다. **`organization`은 0개**라서 과제 설명의 "8종, 1,887개"와 맞지 않는다.
- dev와 test는 **같은 템플릿 23종**을 쓰고, 인물도 대부분 겹친다 (test 72명 중 65명).
  → test 점수만으로는 일반화를 보장할 수 없다. holdout이 진짜 시험이다.
- 주민번호·계좌·카드번호는 형식이 하나씩뿐이다. 전화번호 형식은 8가지다.
- 어려운 사례: 이름만 쓰는 경우(given) 59건, 동명이인 4쌍, 라벨 없는 성+직함(`허 부장님`) 57건
- dev에는 상담 문서가 많고, test에는 업무메일·회의록·메신저 같은 사내 문서가 많다.

**채점기 (`run_compare.py`)**
- 지표: strict, partial, mask_rec (개인정보 용도에서는 재현율과 mask_rec 우선)
- 주의: 과제 설명의 `+정규식` 보강·합집합 기능은 이 파일에 없다. 예측이 중복되면 정밀도가 떨어진다. `ms`는 탐지기가 직접 기록한 값이다.

### 5. 규칙 탐지기 v2: 주소 + 이름
- **주소**: `시·도 → 시·군·구 → 도로명+번호 → (동·호·층)` 순서의 정규식
- **이름**: 2단계 방식
  1. 씨앗 찾기: 뒤에 호칭·직급, 앞에 항목명(`성명:`), 메신저 형식, 소속 뒤, `○○○입니다`
  2. 퍼뜨리기: 같은 문서 안의 같은 이름(띄어 쓴 형태, 조사 붙은 형태, 성 뺀 이름)까지 확장
- 일반 성씨 목록만 사용했다. `personas.json`은 쓰지 않았다 (정답을 미리 보는 것과 같음).
- 첫 실행에서 정밀도 0.909 → 오탐(`문의는`, `민원인`, `고객명`)을 보고 아래를 추가했다.
  - `NOT_NAME`: 항목명 단어 제외
  - `BAD_LAST`: `는/를/에/의`로 끝나는 후보 제외
  - 복성(남궁 등) 지원, `입니다` 뒤 경계 허용

| dev | 재현율 | 정밀도 | mask_rec |
| --- | --- | --- | --- |
| v2 | 0.996 | 1.000 | 0.999 |

- 남은 미탐 2건: `은서랑`, `소율이랑` (성 없이 처음 등장). 이 문장에만 맞는 규칙이 되므로 일부러 고치지 않았다.
- ⚠️ dev를 보며 맞춘 규칙이라 과적합 위험이 있다.

### 6. Kiwi 설치 및 v3: `--kiwi` 옵션

### 22. LLM 개선: JSON 재요청 + 후처리 규칙
- `detectors/llm_hcx.py`에 추가:
  - **JSON 재요청** (`--json-retries`, 기본 2): JSON이 깨지면 틀린 답을 보여주고 "올바른 JSON으로 다시 써라"라고 이어서 요청. temperature 0이라 같은 질문을 그대로 반복하면 같은 답이 오기 때문이다.
  - **후처리 규칙** (`--post-out`): ① 라벨 이름 맞추기(`name`→`person` 등) ② 이름에 붙은 소속·직함 떼기(`채권관리팀 이상훈`→`이상훈`, `민준씨`→`민준`) ③ 떼고 나서 성 한 글자만 남으면 버리기(`김 대리`, `정 부장`)
- 한 번 실행으로 두 파일을 만든다: `preds/llm_hcx_retry_dev.jsonl`(재요청만), `preds/llm_hcx_post_dev.jsonl`(재요청 + 후처리). 같은 HCX 답에서 나온 것이라 후처리 효과만 정확히 비교된다.
- 채점: `results/dev_llm2/`

### 40. 용어 정리: "거르기" → "후처리"
- 하이브리드에서 LLM이 더한 것 중 개인정보가 아닌 것을 버리는 단계는 탐지가 끝난 뒤 결과를 손보는 **후처리**다. 비교표 이름을 `+ 거르기`에서 `+ 후처리`로 바꿨다 (`tools/make_compare_table.py`, `docs/탐지방식_비교표.md`).

### 41. 후처리 정의 문서

- 후처리는 두 가지: ① 형식 정리(`post_process`, LLM 답 전체, 라벨 통일·지어낸 라벨·숫자 라벨 확인·소속/직함 떼기·성+직함 버리기) ② 하이브리드 후처리(`keep`, LLM이 새로 더한 것만, 회사·부서명·역할 단어·이름 모양 아님·대표번호·한글 섞인 숫자 버리기)

  - 전체 기준 순위 1위: **규칙(팀장님) + gpt-5.5** — mask_rec 1.000 / R 0.998 / P 0.997 / 미끼 오탐 0 / 일관성 100% / 1.8초/문서. 규칙 단독(R 0.988)보다 재현율이 오름
  - 서로 메우기: 팀장님 규칙이 놓친 12개를 GPT 모델은 모두 잡고, HCX-007은 11개 (둘 다 놓친 것 1개)
- 주의: test 점수는 팀장님 규칙 쪽이 낙관적일 수 있음 (64번). synth_holdout에서 하이브리드 효과는 아직 재지 않음

### 66. 표 이름 '규칙(팀장님)' → '규칙 기반'
