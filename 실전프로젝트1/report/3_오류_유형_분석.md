## 3-2. 방식별 대표 사례와 원인

**규칙 기반 — 미탐형 약점 (문맥 없는 이름)**

| 유형 | 사례 (【 】 = 정답) | 원인 |
|---|---|---|
| 미탐 | 메신저 `알겠어. 【현준】이랑 같이 정리해서 올릴게` (test 미탐 12건 중 다수) | 성 없이 처음 나오는 이름. 호칭·필드 같은 문맥 단서가 없고 `현준이랑`은 일반 단어와 구분이 안 됨 |
| 미탐 | `카드운영팀 【정현준】` (인사 발령 목록) | 부서명 뒤에 공백 하나로 붙은 이름. 필드·직급 단서 없음 |
| 경계 | `【은영】이랑` → `은영이` | 호격·조사 `이`를 이름의 일부로 퍼뜨림 |
| 오탐 (v7까지) | `【고객명】: 이재원` → `고객명`을 이름으로 | 형태소 분석기가 사전에 없는 단어로 보고 성씨 글자(`고`)로 시작해 이름 후보가 됨. v8의 서식 항목 규칙(⑧)으로 test 오탐 0 |
| 오탐 (일상 문서) | `배송지`, `장인상`(부고), `신청일`, `서울숲` | 같은 원인. 장소 접미사·합성어 필터(부록 A-3의 v6)와 v8 서식 항목·부고 규칙으로 대부분 해결. 콜론 없이 문장 안에 쓴 `배송지`(15건)는 아직 남음 |

형태소 분석기의 한계도 드러났다: Kiwi는 `오세린`을 `오(숫자 5)+세(나이)+린`("다섯 살")으로, `이우리`를 `이(감탄사)+우리`로, `백승훈님`을 `백(숫자 100)+승+후+ㄴ`으로 분석했다. 그래서 품사만으로 이름을 판단하지 않고, 필드·호칭·말하는 사람 형식 같은 문맥 규칙으로 보완했다. 분석기 5종 비교(Kiwi·Komoran·Kkma·Hannanum·Okt)에서도 **사전에 없는 단어를 표시해 주는 Kiwi**가 이름 재현율 0.985로 가장 높았다(Okt·Hannanum은 0.2 미만).

**토큰 분류 (atonlee) — 오탐·경계형 약점**

| 유형 | 사례 | 원인 |
|---|---|---|
| 오탐 | `내일까지 보고서 【달래】` (12건) | 구어체 동사 `달래`(달라고 해)를 이름으로 봄 |
| 오탐 | `하린 포인트 카드`의 `하린` (11건), 회사명 `미르보안` (v7에서 6건) | 상품·회사 이름이 사람 이름처럼 생김. `미르보안`은 v8 회사 이름 끝말 후처리로 제거 |
| 경계 | `정하은` → `정하`, `손하은 책임` → 직함까지, 주소 뒤 조사 `…1301호로` | 서브워드 조각 단위 예측이라 이름 끝·조사 경계가 흔들림 |
| 미탐 | 붙여 쓴 지역번호 `0239644249` | 학습 데이터에 드문 형식 |
| 라벨 오류 (일상 문서) | 점 구분 계좌 `003.004900.35793`, 2묶음 계좌를 다른 라벨로 | 계좌 형식을 좁게 학습 → 일상 문서 계좌 재현율 0.731 |
| 정밀도 (일상 문서) | 주문·접수번호 등 13자리 숫자를 주민번호로 | 일상 문서 주민번호 정밀도 0.66(v7) → 0.81(v8, `○○ 번호` 문맥 후처리) |

**LLM (gpt-4.1-mini) — 미탐형 약점 (지시 과잉 적용·비결정성)**

| 유형 | 사례 | 원인 |
|---|---|---|
| 미탐 | 메일 서명의 직원 직통번호 `02-3961-1452` | "대표번호·내선번호 제외" 지시를 직통번호까지 넓혀 적용 |
| 미탐 | `【상훈】아, 오늘 회의 자료…` (이름만 부르기, given 재현율 0.455) | 메신저 호칭을 이름으로 보지 않음 |
| 미탐 | `리스크관리팀 【허수아】` (3회 실행 모두 반복 누락) | 같은 이름을 일관되게 놓침 |

| 오탐 | `내선 【5647】`을 전화번호로 | 내선번호 판단 오류 |

**규칙 + 토큰 — 미탐 0, 오탐은 토큰 쪽에서 들어옴**

- test 미탐 0: 규칙이 놓친 이름만 쓴 경우를 토큰이 잡고, 토큰이 놓친 붙여 쓴 번호를 규칙이 잡음 (서로 약점이 겹치지 않음)
- 오탐 26건은 모두 토큰의 오탐(`달래` 12, `하린` 11, `이첩` 3)이 그대로 들어온 것 → 정밀도 0.976 (하한선 0.90 위)
- 경계 3건은 규칙의 `은영이` 유형

## 3-4. 정답 데이터 자체의 문제

- 일상 문서 정답은 생성 모델이 표시해 **표시 누락**이 있다(`예금주: 정세림`, `김미영 부장님`, 집 주소 등 → 탐지기가 맞게 잡아도 오탐으로 채점). 검수 후보 44건을 뽑았고(`results/synth_qc_candidates.csv`), 팀 기준(장소 주소 제외)으로 정답을 다시 맞추면 일상 문서 정밀도와 주소 재현율이 더 정확해진다.
- 제공 데이터에는 `김 과장` 같은 성+직함이 정답에 없다(dev 17, test 40건). 팀 기준과 같아 오탐으로 처리했다.
