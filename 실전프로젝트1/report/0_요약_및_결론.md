## 요약

| 항목 | 결론 |
|---|---|
| **운영 탐지기** | **규칙 기반(정규식 + Kiwi) + 토큰 분류 모델(atonlee) 전체 합집합** |
| 선정 이유 | 모든 시험 데이터에서 놓친 개인정보가 가장 적음 — test mask_rec **1.000**, 처음 보는 일상 문서 mask_rec **0.988**. CPU만으로 문서당 약 0.06~0.11초(1만 건 약 10~19분), 결과가 항상 같고, 원문이 외부로 나가지 않음 |
| **멘토 holdout** (처음 보는 문서 유형 19종) | **개선 전**(코드 그대로 먼저 채점): mask_rec **0.993**, strict F1 0.944, 정답 912개 중 미탐 3개, 문서당 48.1ms → 선정 유지. 오류 분석 후 v8로 고쳐 0.995 / mask_rec 1.000이 되었지만 **holdout에 맞춘 값이라 일반화 성능이 아님**. 고친 뒤 dev·test·일상 문서 점수는 떨어지지 않았고 정밀도는 올랐음(test 0.968 → 0.976) |
| LLM의 역할 | **탐지에는 쓰지 않고 RAG 답변 생성에서만 사용** (마스킹된 텍스트만 전달). LLM을 더해도 재현율은 오르지 않고, 약 16~29배 느리며, 원문을 외부로 보내야 함 |
| **2차 평가 세트** (v9) | 모든 세트를 한 번 이상 본 뒤라 새로 생성: 금융 업무 문서 1,775건(평가 전용)과 어려운 표기 782건(반은 개선용, 반은 평가용). 개선용 오류만 보고 고친 v9에서 평가용 반 strict F1 0.781 → 0.861 · mask_rec 0.933 → 0.964, 금융 업무 문서 0.855 → 0.920 · 0.976 → 0.983. dev·test·멘토 holdout은 그대로. **이름 재현율은 거의 그대로(0.836 → 0.843)**라 남은 가장 큰 약점 (부록 A-4) |
| 우선 지표 | 재현율·mask_rec(놓치지 않기) → 정밀도는 하한선 0.90 → 속도 → 일관성 |
| 데이터 사용 | 개선은 dev(와 추가 데이터의 개선용 절반)로만, test는 중간 확인. 초기에 test 오류를 본 이력이 있어 그대로 밝힘(부록 개선 과정과 데이터 사용 기록). 멘토 holdout은 개선 전 점수를 먼저 기록한 뒤 분석·개선(2부) |
| 수치 기준 | 1부(①~④)는 v8 값(v9에서 dev·test 변화 없음), 2부 ⑥은 개선 전(v7) 값, ⑧은 개선 전후 비교와 v9 뒤 재확인 |

## 한계와 다음 단계

- **holdout 개선 후 점수는 일반화 성능이 아니다.** 진짜 일반화는 새 데이터(다음 holdout, 실제 문서)로 다시 재야 한다. 남은 holdout 오류: 한 글자 이름 `린`(미탐), 형용사 `정다운`(오탐 8) — 일반화 위험이 커서 고치지 않음.
- **정밀도 개선 여지**: test 합집합의 오탐 26건은 모두 토큰 모델의 구어체·상품명 오탐(`달래`, `하린`, `이첩`)이고, 일상 문서에서는 문장 안 `배송지`(규칙 15건)가 남았다. 멘토 holdout 개선 전 정밀도는 0.912로 하한선 0.90에 가까웠다. 문맥 없는 이름 후보에 신뢰도를 매겨 "규칙과 모델이 모두 동의할 때만" 채택하는 방식을 검토한다.
- **이름이 가장 큰 약점**: 어려운 표기 평가용 반에서 이름 재현율 0.843, 정밀도 0.871(하한선 아래). `하늘`·`가람` 같은 일반 단어 이름, 메신저 호격, 성 없는 이름은 규칙으로 일반 단어와 구분하기 어렵다. 이름 쪽 토큰 모델을 더 크게 하거나 이런 표기로 미세 조정하는 방법을 검토한다.
- **추가 데이터의 정답 품질**: 일상 문서 정답 검수(44건)를 팀 기준으로 마치면 수치가 더 정확해진다.
- **LLM 하이브리드는 처음 보는 문서에서 재지 않았다.** 다만 속도·외부 전송·일관성 문제는 데이터와 무관하다.
- 실전 2로 넘길 것: 같은 사람의 다른 표기(`윤 선영`/`윤선영`, `010.0349.2063`/`01003492063`) 정규화, 동명이인 구분, 메신저 호격 조사(`은영이`) 제거.

## 재현 방법과 파일 위치

```
cd 실전프로젝트1
python -X utf8 run_detect.py --detector rules --split test
python -X utf8 run_detect.py --detector atonlee --split test
# holdout: --split holdout (멘토 파일 holdout/holdout_labeled.jsonl)
python -X utf8 make_union.py --out preds/combined/rules+atonlee_test.jsonl preds/rules_test.jsonl preds/atonlee_test.jsonl
python -X utf8 run_compare.py --gold data/pii_synth_finance_test.jsonl --pred rules+atonlee=preds/combined/rules+atonlee_test.jsonl --out results/check
python -X utf8 experiments/compare_systems.py          # 규칙 / 토큰 / 규칙+토큰 비교표
python -X utf8 tools/make_compare_table.py test --rank  # LLM 7종 비교표 (팀원)
```
