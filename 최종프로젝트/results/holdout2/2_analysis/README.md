## 1. 탐지 오탐 (정밀도 0.937)

이름 오탐 307건 중 300건이 **14개 단어**입니다. 모두 양식에 반복되는 일반 단어입니다.

| 단어 | 건수 | 나온 곳 | 잡은 부분 |
|---|---|---|---|
| 기안 | 80 | 결재보고서 결재란 `\| 기안 \| 검토 \| 승인 \|` | 모델 (검수 신호 없음) |
| 양도인·양수인·양도 | 86 | 포인트이관신청 `[양도인] 성명:` | 모델 |
| 소보 | 41 | 이의제기회신 문서번호 `소보-2026-3148` | 이름 보태기 모델 |
| 안 돼요 | 40 | 해외결제차단해제 "카드가 안 돼요" (성 '안' + 말) | 규칙 |
| 이수일 | 20 | 교육이수보고 표 머리 '이수일'(이수한 날) | 규칙 (검수 신호 없음) |
| 임계값 | 15 | 시스템장애보고 "모니터링 임계값" (성 '임') | 규칙 |
| 반송·새봄·청솔·Saebom 등 | 18 | 업무 말, 회사·은행 이름 | 이름 보태기 모델 |

- 주민번호 오탐 24건: **법인등록번호** (`법인등록번호: 118023-3131332`). 모양이 주민번호와 같은 6-7자리이고, 앞의 라벨을 보지 않음
- 계좌 오탐 13건: 시스템장애보고의 **서버 IP** (`서버: 10.78.215.206`). 보완 규칙(긴 숫자 → 번호 토큰)이 점을 뺀 숫자를 계좌로 봄
- 주소 경계 오류 2건: 끝 괄호 `(치평동))` 를 하나 더 먹음
- 가리기 재현율이 0.992 로 높아서, 오탐은 **필요 없는 곳을 더 가린 것**입니다. 검색에서 '기안' 같은 단어가 토큰이 되는 부작용은 있지만 노출 위험은 아닙니다

## 2. 탐지 미탐 (이름 46, 전화 15) → LLM 입력 유출 8

| 유형 | 건수 | 예 (모양) | 문서 종류 |
|---|---|---|---|
| 한글로 읽은 전화번호 | 15 | `공일공 팔사칠칠 일이공구` | 챗봇상담로그 |
| 한 글자 이름 | 20 | `채권관리팀 혁입니다`, `윤 고객님`, `총무 율 님` | 채무조정상담 등 |
| 로마자 이름 | 12 | `This is Seongyul Kim`, `Best regards, ...` | 영문고객메일 |
| 표 안 이름 | 12 | 콜백요청목록 담당 칸 `\| 영결 \|` | 콜백요청목록 |
| 고객 + 이름 | 2 | `고객 공지별 요청으로` | 한도일시상향 |

- LLM 입력 유출 8건은 모두 위 미탐입니다. 전화 3건(Q2125)과 로마자 이름 4건(Q2045, Q2048), 그 밖의 이름 1건입니다. 원 답변과 최종 답변에서는 0건입니다
- 미탐은 검수 신호도 거의 없습니다. 화면 업로드였다면 대부분 자동 저장됐을 문서입니다

## 3. 검색 (Hit@1 0.910)

1위를 놓친 질의는 14개입니다.

- **재순위 무효 (실행 오류)**: `search._rerank` 가 LLM 답에서 `[A-Z]\d{4}` 로 ID 를 뽑아 5자리 ID 를 못 알아봄 → 원래 순서 그대로. 메모리 안에서 정규식만 바꿔 다시 돌리면
  | | 첫 실행 | 재순위 고침 (참고) |
  |---|---|---|
  | ALL Hit@1 / MRR | 0.910 / 0.931 | **0.929 / 0.944** |
  | hybrid_paraphrase Hit@1 | 0.800 | 0.933 |
  | homonym_role Hit@1 | 0.375 | 0.500 |
  | address_partial MRR | 0.925 | 0.950 |
  LLM 재순위라 다시 돌리면 조금씩 다를 수 있습니다
- **동명이인 역할 (homonym_role)**: 사람 잇기가 동명이인을 한 사람으로 합침. 도재호(직원·고객)와 조수현(직원·고객)이 DB 에 1명씩만 있습니다. 그래서 질의의 '직원'·'고객'으로 고를 사람이 없습니다. 변혁은 2명으로 잘 나뉘었지만, 질의 "고객 변혁 건만"에서 '변혁'을 이름으로 못 잡았습니다(일반 단어)
- **값 표기 다름 (Q2083)**: 질의 `1705566902686`(13자리 붙여 씀)을 카드번호로 보았는데, 문서에는 계좌 `1705-566-902686`. 라벨이 달라 토큰이 안 맞음
- **미탐이 검색 실패로 (Q2140)**: 문서 H20494 의 '공지별'을 못 가려 토큰이 없음
- **정답 문서에 이름 일부만 (Q2044)**: 질의는 '이성리'인데 문서에는 "총무 성리 님"만 있음 (정답 라벨도 이 '성리'를 개인정보로 안 침)
- **의미 검색 (Q2126 "영어로 온 고객 문의 메일")**: 영문 메일이 안 나오고 콜백요청목록이 나옴. 한국어 질의와 영문 본문 사이 임베딩 거리 문제

## 4. 고칠 순서 제안

1. **실행 오류: 문서 ID 자릿수 가정 없애기** — `search._rerank`, `chat._CITE`·`_CITE_WORD`, 채점 `run_pipeline._CITE`. 고친 뒤 결과는 `3_fix_*` 에 따로 저장합니다
2. (선택, 성능 개선 — Holdout2 를 보고 맞춘 점수로 따로 표시)
   - 오탐: 양식 단어(기안·양도인·양수인), 라벨 뒤 번호(법인등록번호), IP 주소 제외
   - 미탐: 한글로 읽은 전화번호, 로마자 이름
   - 동명이인: 역할이 다른 같은 이름을 합치지 않기
