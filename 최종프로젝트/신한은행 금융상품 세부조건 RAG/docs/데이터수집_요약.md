# 데이터 수집 요약 (2026-11-09 마무리)

담당 RAG: **신한은행 직원 보조용 금융상품 세부조건 RAG** — 직원이 모든 상품의 세부 내역을 알 수 없으니 상품 조건·금리·판매 여부를 근거와 함께 답하도록 보조.
범위: **신한은행 하나**, 상품공시 '판매 중인 상품' 전체 + 고시 금리 + 판매 중지 목록. 금감원 API는 쓰지 않음.

## 4. 검증 요약
- 연결표 문서 247개 = 폴더 PDF 247개 (누락·남는 파일 0)
- 2-2: 247개 문서 모두 숫자 보존 (원문 숫자 = 남은 숫자 + 지운 줄 숫자)
- 2-3: 사본 쪽에만 있는 정보 없음, 요약 쪽은 본문과 다른 경우가 있어 제외 (예금자보호 5천만원 vs 본문 1억원)
- 고시 금리: 예금 92개 상품 체크섬 재수집 일치, 대출 산식(최저 = 기준+가산−우대) 172행 중 170행 일치(나머지 2행은 이차보전 등 원문 값)
- 판매 중지 목록: 탭마다 사이트 총건수 = 수집 행 번호 1~N
- OCR: 원본 이미지와 대조 — 본문 정확, 복잡한 표는 셀 순서 섞임

## 6. 주의 사항
- **개인 식별 정보**: 사용자가 내려받은 PDF 이미지에 다운로드 기록 워터마크(가려진 이름·ID)가 찍혀 있음. 텍스트에서는 제거했지만 **원본 PDF는 외부에 공유하지 않음** — GitHub 저장소는 비공개로 전환 후 올렸으므로 **다시 공개로 바꾸지 않음**
- 데이터 기준일이 지날수록 금리·판매 여부가 바뀔 수 있음 → 답변에 기준일 표시, 재수집 주기 필요
- 사이트 내부 API는 쓰지 않음 (화면 표만 읽음), 자동 수집을 자주 돌리지 않음
