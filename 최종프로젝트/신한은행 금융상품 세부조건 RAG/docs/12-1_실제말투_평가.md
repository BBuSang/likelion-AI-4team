# 12-1 실제 말투 평가 — 같은 사실을 단정한 말투와 실제 말투로

## 왜
- 지금까지 평가 질문은 직원 말투로 만들라고 했지만 대부분 "○○의 가입 대상은 어떻게 되나요?"처럼 단정한 문장
- 실제 영업점 말투(짧은 반말, 줄임말, 오타·띄어쓰기 없음, 고객 상황 섞기, 질문 두 개 한 번에, 구어체 숫자)에서도 버티는지 잰 적이 없음

## 설계 — 짝 비교
- 사실 하나마다 **단정한 질문(formal)**과 **실제 말투 질문(real)** 두 개. 정답·근거가 같으므로 결과 차이 = 말투의 영향
- 실제 말투: 단정한 질문을 뜻은 그대로 두고 6가지 말투 중 1~2개로 바꿔 씀 (앞 대화가 있어야 하는 말·정답은 넣지 않음)

## 세트 — `analysis/s31_realistic_set.py` (OpenAI 생성, 상품 단위 dev/test, test 잠금)

- 질문 수는 사실의 2배 (dev 56 · test 56)
- 말투 사용 횟수: 오타·붙여 쓰기 21 · 숫자 17 · 줄임말 17 · 짧은 반말 10 · 질문 두 개 9 · 고객 상황 9
- 만들면서 고친 것 (실험 전)
  - 상품 이름까지 기존 세트와 겹치지 않게 하니 상품 사실·없는 값이 거의 안 만들어짐 → 이 세 종류는 **섹션만** 겹치지 않게 (판매 중지·비교는 이름도 제외)
  - 공통 약관은 "그 조항이 이 상품 종류에 적용되는지" LLM 확인을 거침 (10-1 교훈) → 3개 걸러짐
  - 보완 정답(s17)은 질문마다 따로 판정되므로 같은 사실의 두 질문이 같은 정답을 쓰도록 **합침**
  - dev 판매 중지에서 '보증대출'(너무 일반적인 이름)을 뺌
- test sha256: retrieval `c46d17123b0a5ef321ca859a6917978b98a51f3aa2d022d9d0083ba8f1eae307` · absent `c7c3445aef61f93d07577f77eafeb9979b8b2440142237bc338048a6f3364138` · status `bce252787ca9be76cf77f1c8562f27a97bab081d9ca00b146b0041a11b2b6cdb` · compare `ca1c1d0b5909a83648caf2c2ee7fc9d1fceef0da0ba335829ae670ef0a24a154`
- 한계: '오타·붙여 쓰기' 말투는 문장 전체를 붙여 쓴 경우가 많아 실제보다 심함(가장 나쁜 경우) · '질문 두 개'의 덧붙은 질문은 정답 근거와 무관(채점은 원래 질문만) · 없는 값 1개는 고시 금리가 있는 상품의 금리 질문(문서에는 없음)

## 무엇을 재나 (지금 방식 v9 그대로)
| 종류 | 지표 |
|---|---|
| 상품 사실·공통 약관 | 검색 보완 Hit@1·Hit@5 (점수형 재순위), 답변 정답 (LLM) |
| 없는 값 | 지어냄 수, 잘 거절함 |
| 판매 중지 | 판매 중지라고 안내 |
| 비교 | 두 값과 결론이 맞음 |
- 핵심: **실제 말투 − 단정한 말투** 차이

## 판단 기준 (test, 결과 보기 전 기록) — 개선 실험이 아니라 "지금 시스템이 실제 말투에서 얼마나 버티는지" 재는 것
| 항목 | 버틴다고 볼 기준 |
|---|---|
| 상품 사실·공통 약관: 검색 보완 Hit@5 | 실제 말투가 단정한 말투보다 0.10 넘게 떨어지지 않음 |
| 상품 사실·공통 약관: 답변 정답 | 15%p 넘게 떨어지지 않음 |
| 없는 값: 지어냄 | 실제 말투에서도 0 |
| 판매 중지: 판매 중지라고 안내 | 실제 말투가 1개 넘게 적지 않음 |
| 비교: 맞음 | 실제 말투가 1개 넘게 적지 않음 |

## 결과 (지금 방식 v9, 조정 없음)
### dev
| 항목 | 단정한 말투 | 실제 말투 |
|---|---|---|
| 검색 보완 Hit@1 · Hit@5 (17) | 0.882 · 1.000 | 0.941 · 1.000 |
| 답변 정답 (17) | 16 (wrong 1) | 15 (partial 2) |
| 없는 값 (4): 지어냄 | 0 | 0 (partial 1) |
| 판매 중지 안내 (3) | 3 | 3 |
| 비교 correct (4) | 3 (partial 1) | 2 (partial 2) |
- 실제 말투의 partial은 '질문 두 개' 말투에서 덧붙은 질문(필요 서류 등)에 "확인되지 않음"이라고 하거나, 비교에서 두 값은 맞고 결론 문장이 없는 경우 — 원래 질문에는 모두 맞게 답함
- 오타·붙여 쓴 상품 이름('신한Value-up글로벌주식외화예금')도 상품명 찾기가 추정으로 찾아 "○○을 △△으로 보고 답합니다"를 붙임

- **실제 말투에서도 떨어지지 않음** — 상품명 찾기의 줄임말·추정(9장)이 오타·붙여 쓰기·별명을 흡수
- 실제 말투 wrong 1개(RT007R 공유형모기지론 수익형 처분손실 계산)는 단정한 말투에서도 실패(no_answer) — 말투 문제가 아니라 계산 질문의 해석(수익형은 손실을 정산하지 않는다는 조항 vs 정답의 손익공유형 예시)
- 비교 partial(RT051): '쏠편한 입출금통장의 보통예금' 금리는 두 말투 모두 못 찾음. 실제 말투는 붙여 쓴 '쏠편한입출금통장보통예금'을 상품 목록에서 찾지 못했다고 안내
