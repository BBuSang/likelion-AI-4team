문제 (프롬프트로 고칠 것)
1. **표의 값이 근거 문장에 없음**: 표 머리 문장(`… USD 기준, 거주자, 단위: %`)을 source_text로 씀 → 금액 구간·이율 숫자가 근거에 없음 (근거 검사가 잡은 2건, D006도 표 전체 덩어리를 근거로 씀)
2. **외화 금액 단위**: 10만불 미만 → `amount_max=100000`이 '원' 칸에 들어감 → 통화가 있으면 그 통화 단위라고 명시 필요
3. **구간 아래쪽 경계 누락**: `50만불 미만` 구간에 `amount_min=10만불`이 없음, 중도해지 `1개월 미만`에 `term_max_m=1` 없음 → "A 이상 B 미만"이면 양쪽 모두
4. **수수료 종류 오분류**: 외화 현찰 수수료 → `physical_withdrawal`(금·은 실물용)로 분류. `cash_handling`이어야 함
5. **우대 결합 방식 누락**: 카드 우대 "차등적용, 중복적용 불가 최고 3.0%"가 condition에 없음
6. **섞인 표에서 확신 없는 짝을 notes에 안 적음**: ELD 모집기간이율 3.77%는 칸이 비어 있는 행과 떨어진 숫자를 짝지은 것 — 맞을 가능성이 높지만 원문 PDF 확인이 필요하고, 규칙상 notes에 적었어야 함
7. 일부 누락: 금 '예약매매서비스' 스프레드 50% 우대 (두 서비스 이름이 붙어 있는 섞인 표)

## 2차·3차 (프롬프트 수정 후 같은 6개로 다시)
프롬프트에 넣은 것
- 2차: source_text에 그 항목의 숫자가 든 줄을 넣기(표면 값이 적힌 줄, 필요한 줄만 원문 순서대로 발췌 가능), 외화 금액은 통화 단위 + `currency`, 구간 양쪽 경계, `physical_withdrawal`은 금·은 실물만·외화 현찰은 `cash_handling`·세금은 `etc`+"세금", 우대 결합 방식 원문대로, **섞인 표에서 짐작으로 짝지은 값은 notes에 반드시**, 붙어 나온 서비스 이름은 나눠서
- 3차: 2차에서 **산식으로 정해지는 금리**(중도해지 `기본이자율×(1-차감률)…`, 만기후 `일반정기적금 이율의 1/2`)를 '숫자가 없다'며 빠뜨림 → 산식 금리도 rate=null·condition에 산식으로 넣기, 혜택의 value_num은 크기일 때만(`10시경`·`한 달에 한 번` 제외), 항목마다 자기 줄을 근거로

근거 검사도 고침: 줄 단위 발췌 근거를 허용(각 줄이 그 섹션에 원문 순서대로 있어야 함), 숫자는 값으로 비교(`0.01` = `0.01000`). 지어낸 문장은 여전히 잡음

| | 1차 | 2차 | 3차 |
|---|---|---|---|
| 항목 수 | 54 | 60 | 66 |
| 근거 검사 문제 (고친 검사로) | 0 | 0 | 0 |
| notes (짐작한 짝 기록) | 0 | 3 | 5 |

1차 문제 7가지의 3차 결과
1. 표 값이 근거에 있음 — 외화MMDA 금액 구간별 이율마다 `10만불 미만 … 0.01000` 줄이 근거
2. 외화 금액 — `amount_max=100000, currency=USD`
3. 구간 경계 — `10만불 이상 50만불 미만` 양쪽, 중도해지 `1개월 미만 → term_max_m=1`
4. 외화 현찰 수수료 → `cash_handling` 3건
5. 카드 우대 condition에 "차등적용, 중복적용 불가"
6. ELD 3.77%·중도해지 수수료율 구간을 "표 순서로 짝지음, 원문 확인 필요"로 notes에 기록
7. 금 예약매매서비스 스프레드 50% 우대 추가
- 덤: 적금 중도해지이율이 차감률 표(1·3·6·9·11개월 이상 → 80·70·30·20·10%)대로 구간별 5개 항목으로 나뉨, 금 배당소득세 15.4%는 `etc`+세금으로

주의
- 프롬프트를 **이 6개 문서를 보며** 고쳤으므로 6개에서 좋아진 것은 낙관적인 수치. 전체 추출 뒤 **이 6개가 아닌 문서**를 무작위로 골라 원문과 대조해야 함
- 근거 검사는 '그 섹션에 있는 문장인지·숫자가 있는지'만 본다 — 섞인 표에서 짝을 잘못 지은 경우는 못 잡음 → notes가 있는 문서는 `extract_status=needs_review`
