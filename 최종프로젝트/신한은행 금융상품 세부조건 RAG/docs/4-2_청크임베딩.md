## 청크 규칙
| 대상 | 방법 | 결과 |
|---|---|---|
| 문서별 청크 | 정형 문구가 아닌 섹션(2-6 정리본). **짧은 섹션은 같은 큰 제목 안에서 이어 붙여 300자 이상**(900자를 넘지 않게), 조문형처럼 큰 제목만 있는 섹션(제1조·제2조, 머리말)은 이웃끼리도 묶음, 정형 문구는 건너뛰기만 함. **1,500자 넘는 섹션은 줄 경계에서 900자 안팎으로 나누고 한 줄 겹침** | **2,218개** (247개 문서), 길이 p10 148 · 중앙 390 · p90 840 · 최대 1,462자, 100자 미만 137 |
| 공통 조항 | 문서별 청크에 넣지 않고 한 번만 (`[공통 조항 · N개 문서] 제목` 머리말) | 216개 |
| 용어집 | 용어 하나 = 임베딩 하나 | 23개 |
- 처음 규칙(같은 큰 제목 안에서만 묶기)은 100자 미만 청크가 1,091개 → 조문형 이웃 묶기 2,336개(215) → 정형 문구 건너뛰기 2,218개(137)
- 머리말 예: `[신한 운동화 적금 상품설명서] 2. 거래조건 > 가입대상 · 예금과목 · 상품유형 · 계약기간 · 가입금액 · 저축한도 · 가입방법 · 기본이자율 (p.1)`
- 우대이자율 표(1,015자)는 쪼개지지 않고 한 청크 (2-5에서 확인한 것과 같음)
- `tsv`: Kiwi 형태소(명사·동사·형용사 어간·외국어·숫자)로 키워드 검색용 색인
- PDF에서 딸려 온 NUL 문자 8곳은 DB에 넣을 때만 뺌

## 검색 동작 확인 (벡터 검색만, 평가 아님)
| 질문 | 결과 |
|---|---|
| 근질권이 뭐야 | 용어집 `근질권` 1위 ✓ |
| 위법계약해지권 행사 기간 | 공통 조항 `위법계약해지권` 1위 ✓ |
| 장병내일준비적금 가입 대상 | 장병내일준비적금 설명서·특약 1·2위 ✓ |
| 골드바 실물 인출 수수료 | 골드바 약관 `제7조 실물수수료의 징수` 1위 ✓ |
| 외화 MMDA 10만불 미만 금리 | 외화 MMDA 설명서 2개가 1·2위, 다만 금리 표 청크는 아님 △ |
| **운동화 적금 우대금리 받으려면?** | **운동화 적금이 상위 5개에 없음** ✗ (다른 상품 우대 청크가 나옴) |
- 원인: 청크 본문은 상품명 대신 "이 예금"으로 적혀 있고, 상품명은 머리말 한 줄뿐이라 **"○○ 적금의 우대금리"처럼 상품을 지정한 질문에서 벡터 검색이 상품을 못 가림**. 키워드 검색도 일반 단어(우대·금리·적금)에 묻힘
- 상품명으로 문서를 먼저 좁히면(`product` → `product_document`) 운동화 적금 설명서·특약만 남지만, 그 안에서도 우대이자율 청크가 3위 안에 없음 → **상품 지정 + 키워드·벡터 결합 + 재순위**가 필요
