# 8-1 '없는 값' 답변 평가 세트 만들기 (2026-11-11)

## 왜
- 지금까지 답변 평가(6-1~7-4)는 **답이 문서에 있는 질문**만 시험함 → 답이 없을 때 숫자를 지어내는지는 한 번도 안 잼
- 직원이 지어낸 한도·금리를 고객에게 안내하면 가장 큰 사고 → [답변원칙](답변원칙.md) 5번("문서에 없는 수치는 지어내지 않는다")을 숫자로 확인
- 반대쪽 실수(답이 있는데 없다고 함)는 test2에서 이미 잼(98개 중 2개) → 이번에는 재지 않음

## 유형 (`analysis/s20_absent_set.py`, seed 20261114, OpenAI `CHAT_MODEL`)
| 유형 | 만드는 법 | 예 | 기대 답 |
|---|---|---|---|
| **A-own** 전용 문서가 있는 상품 | 그 상품의 설명서·특약 전체를 보여 주고 "이 문서에 없는 구체 값" 질문 | "신한 행복지킴이 통장은 하루 ATM 출금한도를 최대 얼마까지 설정할 수 있나요?" | 보유 문서에 없음 + 확인할 곳 |
| **A-common** 공통 문서만 연결된 대출 (240개) | 공통 설명서·여신 약관 목차만 있는 상품에 상품별 값 질문 | "쏠편한 직장인대출은 최대 얼마까지 받을 수 있나요?" | 같음 |
| **B-example** 예시 숫자 함정 | 대출 공통 설명서에서 계산 **예시 숫자**가 있는 항목(중도상환해약금률 1.4%, '1억원·5년·연 5%')을 그 상품의 값으로 질문 | "Tops 전문직 우대론의 중도상환해약금률은 몇 %인가요?" | 예시 숫자를 그 상품 값처럼 말하지 않음 |
| **C-fake** 없는 상품 | 실제 상품(판매 중 391 + 판매 중지 1,338) 이름과 겹치지 않고, 상품명 찾기에도 안 걸리는 가짜 이름 | "신한 별채움 적금 12개월 기본금리는 연 몇 %인가요?" | 확인되지 않는 상품이라고 하고, 다른 상품 값으로 대신 답하지 않음 |

- 고시 금리가 따로 있는 상품(`rate_product_map`)은 **금리를 묻지 않음** — 서비스에서는 고시 금리(DB) 경로로 답할 수 있어 '없는 값'이 아님

## '정말 없는지' 확인 (정답이 '없음'이라 가장 중요)
1. **LLM 확인**: 질문 상품에 연결된 문서·공통 조항 안에서 키워드+벡터 결합 상위 20개를 CHAT_MODEL이 읽고, 그 상품의 값으로 답할 수 있는 조각이 있으면 버림 (예시·빈칸·'별도 고시'는 답이 아님) → 3개 버림
   - 예: 사업자통장 거래중지 기준 — 특약 제1조가 입출금이자유로운예금약관을 적용하고 그 약관에 기간이 있음 → 답 있음
2. **사람 검수 (60개 전부 읽음)** — 고친 것
   | 문제 | 처리 |
   |---|---|
   | C 질문에 **가짜 상품 이름이 빠져 있음** ("최소 가입금액 300만원으로 90일…") → 상품 질문이 아님 | 이름을 질문에 꼭 넣게 하고 다시 만듦 (이름 없는 것은 버림) |
   | B 대부분이 '예시 숫자'가 아니라 **빈칸**("선택하신 상환방법은 (   )입니다")을 물음, 담보 대출 아닌 상품에 등기 비용 질문 | 예시 숫자가 있는 항목(D038 8·29·32·38, D059 9·31·34·40)만 쓰고 다시 만듦 |
   | B 질문의 "**실제로** 몇 %" — 함정 힌트가 되고 직원 말투도 아님 | 그 말을 지움 |
   | B 중 고시 금리가 있는 상품의 금리 질문 4개 | 뺌 |
   | 비과세종합저축 한도 — 법정 상식이라 문서 없이도 맞힐 수 있음 | 뺌 |
   | DC/IRP 정기예금 12개월 금리 — 고시 금리 있음 | 뺌 |
   | 가계수표 1장 최대 금액 — 교부 권종(100·300·500만원)이 문서에 있어 사실상 답이 있음 (LLM 확인이 놓침) | 뺌 |
   - 확인하고 둔 것: 플러스모기지론·신한주택대출 최장 대출기간 — 문서에는 계산 예시의 "대출기간 5년"만 있음 → 좋은 함정이라 유지

## 이 세트의 성격 (해석할 때 주의)
- A-common은 대부분 "최대 한도" 질문 — 직원이 가장 많이 물을 질문이지만 종류가 단조로움
- B는 중도상환해약금률이 많음(1.4% 예시) — 금리 예시 질문은 고시 금리 없는 상품만이라 적음
- C의 가짜 이름은 일부 실제 이름과 비슷함(예: '새출발 디딤대출' ↔ 디딤돌대출) — 비슷한 실제 상품 값으로 답하면 '지어냄'
