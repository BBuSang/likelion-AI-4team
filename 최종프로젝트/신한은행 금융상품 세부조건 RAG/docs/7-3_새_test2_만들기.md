# 7-3 새 test 세트(test2) 만들기 (2026-11-11)

## 왜
- 기존 test(72개)는 7-2에서 test에서 찾은 상품명 별칭 오류를 고치면서 그 부분이 오염됨 → 처음 보는 상품으로 다시 잠근 시험 세트가 필요
- 사용자 선택: **상품 사실 질문 + 공통 조항·용어 질문** (판매 중지·미보유 값·비교 질문은 이번에 넣지 않음)

## 만든 방법 (`analysis/s19_testset2.py`, seed 20261113, OpenAI `CHAT_MODEL`)
- **안 쓴 것만**: dev·test·별칭 확인 질문에 나온 상품 이름(152개)을 모두 빼고 남은 161개 상품(대출 139·저축 19·기타 2·복합 1), 기존 정답 섹션·공통 조항·용어도 제외
- **A 상품 사실**: 상품을 고르고 그 상품에 연결된 문서의 섹션 하나(정형 문구·머리말 아님, 본문 40자 이상, 같은 섹션은 한 번만) → s11과 같은 지시문으로 직원 말투 질문·짧은 답·근거 원문
  - **절반은 상품을 직원 줄임말로 부르게** (`name_style: nickname`, 예: `SOHO명품대출`, `사잇돌대출`, `쏠가전 대출`), 절반은 정식 이름 (`formal`) → 상품명 찾기까지 공정하게 잼
- **B**: 정형 공통 조항 10개(일부는 상품명 포함) · 용어 6개
- 근거 원문이 정답 섹션에 그대로 없으면 버림 (8개 버림)
- **추가 정답(gold_alt)**: s17과 같은 방식(vec·kw·routed 상위 10개를 모아 CHAT_MODEL이 "그 조각만으로 같은 답"인 것만 표시) → 98개 중 68개 질문에 117개
- 질문 임베딩: **맥에서 KURE-v1을 직접 실행** (`s10_chunks.py embed-questions-local`, sentence-transformers 6.2 + MPS). 코랩 벡터와 같은지 dev 질문 20개로 확인 → 코사인 1.0 (똑같음). 앞으로 새 질문은 코랩 없이 임베딩 가능

## 이 세트의 성격 (해석할 때 주의)
- 안 쓴 상품이 대부분 대출이라 **대출 질문이 많고**, 대출 상품은 공통 설명서·여신거래 기본약관만 연결된 경우가 많아 **상품 사실 82개 중 51개가 공통 문서 5개**(기업대출 설명서 14 · 가계대출 설명서 12 · 여신거래 기본약관(가계용) 10 · 예금거래기본약관 9 · 여신거래 기본약관(기업용) 6)에서 나옴
  → 상품 전용 문서보다 **공통 문서 안에서 맞는 조항을 찾는 능력**과 **줄임말 상품명 찾기**를 더 많이 시험함
- 일부 '줄임말'은 '신한'만 뺀 정도로 가벼움 — 7-2 확인 질문보다 쉬운 편일 수 있음
