## 왜
- test2 답변 실패 2건(7-4)은 답이 상품 전용 문서가 아니라 **공통 약관**에 있었음
- 원인 분석 (test2는 채점이 끝난 세트라 진단에만 씀): 정답이 공통 문서에 있는 상품 질문 61개 중 59개는 찾지만, 실패는 공통 약관 조각이 **재순위 후보(상위 10개)에 아예 못 들어온** 경우 (13위·16위). 다른 1건('청년미래적금 약관 사본')은 상위 20개가 전부 그 상품의 설명서·특약
- **구조적 원인**: 상품 문서 조각은 머리에 `[신한 청년미래적금 상품설명서]`처럼 상품 이름이 붙어 있고 질문에도 상품 이름이 있음 → 주제와 상관없이 상품 이름이 겹친다는 이유로 그 상품 조각이 위로. 공통 약관 조각에는 상품 이름이 없어 밀림. 그런데 이미 그 상품 문서로 범위를 좁힌 뒤라 범위 안에서 상품 이름은 순위를 가르는 데 쓸모가 없음
- dev 105에는 이런 질문이 8개뿐(모두 성공)이라 dev로는 고칠 수 없음 → 새 세트 필요

## 구현 (`analysis/s12_retrieval.py`)
- `topic_query(q, pids)`: 질문에서 찾은 상품 이름(어절)을 뺀 주제 / `text_vec`: 주제 문장 벡터 (KURE, 캐시)
- `rank(..., topic=)`: routed에서 범위를 좁힌 뒤 주제만으로 벡터·키워드 순위
- **최종: `ROUTED_TOPIC=mix`(기본)** — 재순위 후보 10개 = 지금 방식 상위 7 + 주제만으로 매긴 순위에서 빠진 것 상위 3. 재순위 점수가 같으면 지금 방식 순서. `off`(이전) · `on`(주제만) 비교용, `RERANK_QUOTA`(공통 문서 몫) 비교용
