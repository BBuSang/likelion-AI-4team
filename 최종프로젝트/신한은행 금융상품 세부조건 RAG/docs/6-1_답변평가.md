## 문서마다 값이 달라 보인 3건의 원인 (확인)
| 질문 | 정답(평가셋)의 문서 | 답변이 쓴 문서 | 원인 |
|---|---|---|---|
| A140 쏠편한 입출금통장 '약관' 시행일 | 공통 약관 `입출금이자유로운예금약관` 부칙: 2024.03.29 | 상품 **특약** 부칙: 2018.02.13 · 2026.06.16 · 2026.07.01 | 상품에 '약관'이 두 개(상품 특약 + 공통 약관), 각자 따로 개정·시행, 부칙에 이력이 쌓임 |
| A067 MY 주니어통장 우대 나이 | 설명서 **상품개요**: "만 18세 이하" (요약) | 특약 제8조·설명서 우대서비스: "만 19세가 되는 달의 신규일까지" | 같은 규정을 요약은 대략, 규정 문서는 정확하게 적음 — 모순 아님 |
| A135 수출입 외화예금 준용 약관 | 공통 `외화예금거래 기본약관` 제6조 (일반 목록) | 상품 특약 제1조 (이 상품의 목록) | 층마다 적용 약관 목록이 다름, 상품 특약이 더 구체적 |
- 공통 원인: **한 상품 = 설명서(요약·안내) + 상품 특약(상품 전용 규정) + 공통 약관(여러 상품 공통)** 의 3층 구조, 층마다 같은 주제를 다른 수준으로 적고 따로 개정됨. 평가셋은 섹션 하나만 보고 질문·정답을 만들어 다른 층을 모름
- 세 건 모두 **데이터 오류(서로 모순)는 아님**
- 대응: 답변 때 근거 문서의 층(상품 특약 / 공통 약관 / 설명서 요약)을 알려 주고 약관 적용 순서(상품 특약 우선, 예금거래기본약관 제23조 '약관적용의 순서')로 답하기, 값이 여러 개면 "문서별로 다름"으로 안내. 평가셋은 문서 종류를 질문에 넣거나 같은 내용의 다른 문서도 정답으로 인정
