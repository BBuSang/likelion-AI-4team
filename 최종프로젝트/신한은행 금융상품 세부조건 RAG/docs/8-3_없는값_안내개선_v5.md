# 8-3 '없는 값' 안내 개선 — 답변 원칙 v5 (2026-11-11, dev로만)

8-2에서 지어낸 값은 0이었지만, 안내 문구 두 가지를 고치기로 함. test 28개는 손대지 않음.

## 바꾼 것 (`analysis/s15_answer_eval.py` `prompt_of("v5")`, `answer_input`)
| | v4 | v5 |
|---|---|---|
| 확인할 곳 | "상품설명서나 영업점에서 확인" — 이미 근거로 본 설명서를 다시 보라고 함 | **이미 받은 문서를 다시 보라고 하지 않음**. 대출의 한도·기간·금리·수수료율 → "여신 시스템 또는 영업점 여신 담당", 예금·기타 → "영업점 또는 신한은행 홈페이지 상품 안내" |
| 상품명을 못 찾은 질문 | 값만 "확인되지 않음" | 입력 맨 앞에 `[상품명 찾기]` 결과를 알려 줌. 못 찾았고 근거에도 그 상품 문서가 없으면 **"보유 상품 목록에서 '○○'을 찾지 못했습니다 → 정확한 상품명 확인 → 이름이 맞다면 영업점·홈페이지에서 확인"**. 없는 상품이라고 단정하지 않음(줄임말일 수 있음), 다른 상품 값으로 대신 답하지 않음 |
- 근거에 그 상품으로 보이는 문서가 있으면(줄임말로 부른 실제 상품) 그 문서로 답하고 어느 상품 문서 기준인지 밝힘
- 고치는 중 발견: 답변 캐시 키에 프롬프트 내용이 없어 문구를 고쳐도 예전 답을 재사용함 → v5부터 키에 프롬프트 해시를 넣음
