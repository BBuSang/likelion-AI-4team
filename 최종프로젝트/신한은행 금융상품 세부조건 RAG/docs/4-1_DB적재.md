## 질의할 때 주의 (답변 단계에 넘길 것)
- 같은 상품에 기간·구간별 `max` 행이 여러 개 → 상품별로 묶어서(최댓값 또는 구간 표시) 답해야 함
- 설명서 금리는 **문서 기준일** 값, 고시 금리는 **수집일** 값 → 숫자는 고시 금리 우선, 둘 다 날짜 표시 ([답변원칙](답변원칙.md))
- 대출은 설명서에 연체이자율 정도만 있음 → 대출 금리 숫자는 고시 금리(`rate_notice`)와 산출 가정으로
- `needs_review` 문서의 숫자는 답변에 쓸 때 원문 근거(`source_text`)를 함께 보여 주는 것을 권장
