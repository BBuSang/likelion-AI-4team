## 2. 표형 설명서의 행 이름 (109개 중 등장 문서 수)
가입대상 105, 세제혜택 100, 예금자보호 99, 기본이자율 98, 지급방법 65, 계약해지방법 64, 거래제한 64, 예금과목 58, 이자율 50, 일부해지 46, 담보제공 46, 계약기간 46, 이자산출근거 45, 수수료 43, 중도해지 42, 양도 42, 재예치 41, 우대이자율 37 …
- **행 이름이 줄바꿈으로 쪼개짐**: `휴면예금및`+`출연`, `원금및`+`이자지급제한`, `자료열람`+`요구권`, `원금또는이자`+`지급관련제한` → 행 이름 사전 + 이어 붙이기 필요
- 행 이름 아래에 기준일이 붙음: `기본이자율 / (2026.10.16 / 현재, 세전)` → 기준일은 메타로 따로 뽑기
- 우대이자율 표는 쪽을 넘어감 (예: 운동화 적금 p.1→p.2), 표 안에 `항목 / 우대 요건 / 우대 이자율` 열이 한 줄씩 풀려 있음

## 3. 예외 표시

| 표시 | 수 | 문서 | 처리 방향 |
|---|---|---|---|
| **요약 상품설명서 쪽** | 95 | 표형 설명서 대부분 — 문서 **끝 쪽**에 '○○ 요약 상품설명서' 1쪽 | 본문과 중복 → 청크에서 제외 (쪽 번호 `summary_page`에 기록) |

| **띄어쓰기 손실** (no_space) | 11 | 금·은 간이투자설명서 6, 기금대출·디딤돌·공유형 모기지 설명서, 생계비계좌 설명서·특약 | 별도 처리 (띄어쓰기 복원 또는 형태소 기반 검색만) |
| **OCR 필요** | 1 | 청년 주택드림 청약통장 상품설명서 | OCR 또는 제외 |

## 4. 반복 문구 (쪽 머리·꼬리, 130개 문서 이상)
- `준법감시인 사전심사필 제2026-…호` + `(2026. 07. 15 ~ 2027. 07. 14)` → 매 쪽 반복, **메타로 뽑고 본문에서 제거** (심의필 번호 130개 문서에서 찾음)
- 약관·특약: `※ 이 약관은 금융소비자 보호에 관한 법률 등 … 제공됩니다.` (111개) → 제거
- 설명서 첫머리 `◈ 이 설명서는 금융소비자의 권익 보호…` (70개 이상) → 정형 문구(boilerplate)
- 대출 설명서: `은 행 용`, `5-202-0012(21.0×29.7) 중질지(재생용지)`, `신한은행은 친환경용지를 사용합니다.` → 제거
- 기준일(`YYYY.MM.DD 현재/기준`) 찾은 문서 101개 (약관·특약에는 보통 없음)
