# 신한은행 대출 공통 규칙 정리 (2026-11-06)

출처: `data/docs/`의 대출 설명서 9종 (연결표 `data/meta/loan_doc_map.csv` 기준으로 대출 270개에 연결)
- 은행 설명서 4종: 가계대출(85개 상품), 기업대출(139), 전세자금대출(13), 주택담보대출(9)
- 정책대출 설명서 5종: 주택도시기금대출(13), 내집마련 디딤돌(6), 보금자리론(2), 수익·손익공유형 모기지(2), 신혼희망타운 수익공유형 모기지(1)

> 설명서는 상품별 값(금리·한도·해약금률·보증료)을 **빈칸 "( )"**으로 두고 상담 때 채우는 서식이다. 그래서 여기 있는 것은 "규칙"이고, 개별 상품의 수치는 없다.

## 1. 은행 설명서 4종의 공통 규칙 (가계·기업·전세·주담)

| 항목 | 규칙 |
|---|---|
| 중도상환해약금 | 최초 대출취급일로부터 **3년까지만** 부과. 산식 = 중도상환금 × 해약금률 × (잔여일수 / 대출기간). 해약금률은 대출유형·금리종류별로 다르고 매년 공시 (설명서 예시: 1.4%) |
| 해약금 면제 | 기존 계약을 해지하고 사실상 같은 계약을 새로 맺은 경우, 두 계약을 합쳐 3년이 지나면 면제. 청약철회 시 면제 |
| 청약철회권 | 계약체결일·서류수령일·대출금 수령일 중 **늦은 날부터 14일 이내**. 대출금·이자·은행이 낸 인지세·설정비용 반환. 5영업일 안에 대출정보 삭제 |
| 철회권 남용 | 같은 은행에서 **1개월 안에 2회 이상** 철회하면 신규대출 거절·한도 축소 등 불이익. 철회일부터 6개월간 신규대출 제한 |
| 금리인하요구권 | 취업·승진·재산 증가·신용점수 상승 등 신용상태가 개선되면 신청 가능 (시기·횟수 제한 없음). 은행이 금리를 산정하지 않는 상품(협약·정책 금리 등)은 제외. **5영업일 이내** 결과 통지 |
| 위법계약해지권 | 금소법 판매원칙 위반 시, 위반을 안 날부터 1년 이내(계약 후 5년 이내) 요구. 은행은 10일 안에 통지 |
| 자료열람요구권 | 분쟁·소송 목적. 6영업일 안에 열람 제공 |
| 채무조정요청권 | 계좌별 원금 **3천만원 미만** 대출이 연체되면 채무조정 요청 가능. 10영업일 안에 결정 통지. 절차 중에는 기한의 이익 상실 안 됨 |
| 연체이자율 | **대출이자율 + 연 3%**, 최고 **연 15%** (상품에 따라 다를 수 있음) |
| 원금 5천만원 미만 특례 | 연체로 기한의 이익을 잃어도 **만기까지는 원금 잔액에 연체이자를 매기지 않음** (개인채무자보호법) |
| 일부 연체이자 납입 | 연체이자 전액을 낼 때까지 잔액 전체에 연체이율 계속 적용 |
| 연체정보 | **5영업일 이상** 연체 → 단기연체정보 제공(신용점수 하락). **3개월 이상** 연체 → 7영업일 안에 연체정보 등록. 해제 후에도 기록이 최대 1년 남음 |
| 인지세 | 5천만원 이하 비과세 / 1억 이하 7만원 / 10억 이하 15만원 / 초과 35만원, **고객·은행 50%씩** |
| 근저당 비용 | 신규 설정비용(등록면허세·교육세·법무사 등)은 은행 부담, 국민주택채권 매입비·말소비용은 고객 부담. 부담주체 불분명 비용은 50%씩. 고객 취소·심사 거절 시 고객 부담 |
| 금리 구조 | 기준금리(금융채·COFIX 신규/신잔액) + 가산금리(리스크·원가·마진) ± 우대(부수거래 감면 등). 조건 변경(연장 등) 시 금리 바뀔 수 있음 |
| 상환방식 | 원리금균등 / 원금균등 / 만기일시 (1억, 5년, 5% 예: 총이자 1,550만 / 1,500만 / 2,500만원) |
| 연장 | 신용점수 하락·연체 시 거절 가능, 한도대출은 사용이 적으면 한도 감액 |

|---|---|---|---|
| 연체이자 | 이자율 + 연 4%(3개월 이내) / 연 5%(3개월 초과), 최고 연 10% | 이자율 + 연 2%(3개월 이내) / 연 3%(초과), 최고 **연 12%** | 최고 연 10% |

## 4. 데이터 처리에서 발견한 점
- **은행 설명서 4종은 한 파일에 같은 내용이 2번** 들어 있음 (은행보관용·고객보관용 사본) → 청킹 전 앞쪽 사본만 사용
- **정책대출 설명서(기금·디딤돌·공유형 모기지)는 텍스트에서 띄어쓰기가 사라짐** ("연체이자율은연체발생일로부터…") → 검색·임베딩 품질에 영향, 띄어쓰기 복원 또는 별도 처리 필요
- 설명서 뒤쪽의 고객 확인 문구("확인하셨습니까?")와 용어 부록은 규칙이 아니므로 청킹 시 구분 필요
- 같은 질문(예: "연체하면 언제 기한의 이익을 잃나요?")에 대출 유형별로 답이 다르므로, **상품 → 연결 설명서로 먼저 좁힌 뒤 검색**해야 함
