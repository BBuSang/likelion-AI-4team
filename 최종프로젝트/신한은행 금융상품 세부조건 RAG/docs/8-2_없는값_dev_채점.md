## 사람 검수 (32개 전부 읽음)
- **지어낸 값 0개 — LLM 채점과 같음.** 숫자를 말한 답도 모두 "그 상품의 값은 아님"을 밝힘
  - ND00 한 달부터 적금: 납입실적 우대 연 2.0%·최고 연 3.80%를 말하되 "쿠폰 우대금리 최대치로 확인된 값은 아니다"라고 구분
  - ND21 공무원·교직원 신용대출: "안내된 1.4%는 계산 예시이므로 실제 적용률로 볼 수 없다"고 직접 밝힘
  - C의 "30년인가요?", "100만 원인가요?"처럼 **틀린 값을 전제로 깐 질문**에도 "예"라고 하지 않음
- 함정이 잘 안 먹힌 이유: 공통 설명서 자체가 해약금률 항목에 "대출유형·금리종류별로 다르고 실제 적용이율은 매년 공시된 이율"이라고 적어 두어, 그 문장이 함께 검색됨

### 지어냄은 아니지만 고칠 점 2가지
| 문제 | 어디서 | 예 |
|---|---|---|
| **① 없는 상품이라고 말하지 않음** — 값만 "확인되지 않는다"고 해서, 직원은 상품은 있는데 값만 없는 줄 앎. 상품 이름을 잘못 들었을 가능성을 알려 주지 않음 | C 8개 중 5개 (3개는 "근거에 이 상품 문서가 없다"고 언급) | ND24 "신한 천천히 적금의 최소 가입금액은 보유 문서에서 확인되지 않습니다" |
| **② 이미 본 문서를 다시 보라고 함** — 상품설명서를 근거로 찾았는데 없다면서 "상품설명서에서 확인해 주세요" | A·B 대부분 | ND05 "상품설명서의 해당 조건을 확인하거나 영업점에 문의" |
- ①은 [답변원칙](답변원칙.md) 1번("어디에도 없는 상품은 '상품공시에서 확인되지 않는 상품'으로 안내")과 맞지 않음
  - 주의: 상품명 찾기가 못 찾는 경우는 가짜 상품뿐 아니라 **줄임말로 부른 실제 상품**도 있음(7-2: 줄임말 절반을 못 찾음) → "없는 상품"이라고 단정하면 안 되고 "보유 상품 목록에서 이 이름을 찾지 못함 → 정확한 상품명 확인"이 안전
- ②는 답변원칙 5번의 확인할 곳(여신 시스템·상품 안내·영업점)을 쓰면 됨 — 특히 공통 문서만 있는 대출은 상품별 한도·기간을 여신 시스템·영업점에서 확인

## 이 결과의 한계
- 질문이 한 가지 값을 똑바로 묻는 형태라 비교적 쉬움. 여러 상품을 비교하거나 계산을 시키는 질문에서 지어내는지는 아직 모름
- 32개라 "지어냄 0"이어도 실제 비율이 0이라는 뜻은 아님 (32개 중 0개면 95% 신뢰 상한 약 9%)
