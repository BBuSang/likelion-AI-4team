# 신한은행 금리안내 페이지 검토 (2026-11-09)

- 위치: 상품공시 > 저축상품 > **예금금리** (`https://www.shinhan.com/hpe/index.jsp?univ=220#050504090600`) → '바로가기'를 누르면 **'금리안내' 팝업**(iframe)이 열림
- 팝업 탭: 예금 / 대출 / 외환 / 신탁 / 퇴직연금 / 펀드 기준가·수익률 / 주요시장금리 / COFIX 금리
- 확인 방법: 브라우저로 열어서 읽기만 함 (수집기는 만들지 않음)

## 1. 예금 탭
- 하위: 목돈만들기(적금) / 목돈굴리기(정기예금) / 입출금자유 / 세테크재형저축 / 외화예금
- **기준일시 2026.11.09** (오늘), 조회일자를 바꿔 **과거 날짜 금리도 조회 가능**
- 상품 선택(적금 31개) → 이자지급방법 · 금리유형(고시금리) · **가입기간별 기본이율 · 온라인가입 이율**
- 금리 종류별 하위 탭: 만기지급이율 / 중도해지이율 / 만기후이율(1개월·6개월 이내·6개월 초과)
- 안내 문구: "자유적립식은 정기적립식 기간별 적용금리에서 0.1% 차감 (일부 상품 제외)"

### 설명서 금리와 대조 (적금 26개, 기본이율)
- **25개 일치** (설명서 기준일 2026-09-03 ~ 11-02 → 오늘까지 금리 변동 없음)
- **1개 다름**: 신한 사업자 성공기원적금 — 오늘 고시에 **6개월제 연 2.35%**가 있으나 설명서(2026-09-03)는 **1년제만** 있음 → 설명서에 없는 기간이 고시에는 있음
- 이름 맞추기 주의: 설명서 제목 `신한 안녕，반가워 적금`은 **전각 쉼표(，)** — 이름 정규화 필요

## 2. 대출 탭 (가장 중요)
- 하위: 신용대출 / 부동산담보대출 / MY CAR 대출 / 예금담보대출 / 기타대출
- 상품별(신용대출만 54개) **기준금리 종류 · 기준금리 · 가산금리 · 우대금리 · 최저금리 · 최고금리** (2026.11.09 기준)
  - 예) 첫 상품: 금융채(6개월) 3.83% + 가산 2.04% − 우대 1.10% → 최저 4.76% ~ 최고 5.87%
- **산출 가정 문구가 함께 있음**: "대출금액 1억5천만원 / 12개월 / 만기일시상환 / 내부신용등급 3등급 / 전액신용대출 가정 예시", "마이너스통장은 연 0.5% 가산"
- 이름 대조: 신용대출 14개 표본 중 13개가 `products.csv` 이름과 일치 (신한 PAYCO 소액대출만 없음)
- → 설명서에서 빈칸이던 **개별 대출상품 금리를 '예시 범위 + 가정 조건'으로 채울 수 있음**

## 3. 기타 탭 (참고)
- 주요시장금리 · COFIX: 대출 기준금리 설명("COFIX가 뭐예요?", "금융채 6개월 금리는?")에 쓸 수 있음
- 외환·신탁·퇴직연금·펀드: 지금 상품 범위(상품공시 391개)와 일부만 겹침
