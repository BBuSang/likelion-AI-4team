## 발견
1. **예금·ELD 목록에는 판매중지 날짜가 없음.** '변경내용보기' → '거래조건 변경사항'(920건)에 "○○ 판매중지" 공지가 있지만 목록에 날짜 칸이 없고 **날짜는 공지 PDF 안에만** 있음 (예: '신한 적금 9단 판매중지', '2026 신한 SOL KBO 리그 적금 판매중지')
2. **판매 중 목록과 판매 중지 목록에 같은 이름이 13개**: 신한은행 퇴직연금 정기예금(DB)·(DC/IRP), 기업대출 9개(Tops 전문직 우대론, 신한 동물병원 대출 등), 신한MY CAR중고차전환대출 등 → 같은 이름의 옛 판·새 판일 가능성. 이 상품들은 '판매 중지'라고 단정하면 안 됨 (`also_on_sale=1`)
3. 기업대출 목록은 사이트에 같은 상품명이 반복 게시됨(74행 중 고유 이름은 적음)
4. ELD는 회차(예: 26-21호)마다 새 상품이 나오고 판매가 끝나면 판매 중지 목록으로 이동 → 회차 단위로 판매 중지

## 답변에 쓰는 방법 (답변원칙 1번)
- 날짜 있음(대출 대부분): "○○은 **YYYY-MM-DD에 판매 중지**된 상품이에요."
- 날짜 없음(예금·ELD·기업대출 일부): 판매 중지 사실만 말하고 날짜는 "공시 목록에 없음" — 날짜를 추정하지 않음
- `also_on_sale=1`: 판매 중 목록에도 있으므로 "판매 중인 같은 이름의 상품이 있음"을 함께 안내
