# 2-4 문서 메타 추출 (2026-11-06)

- 스크립트: `analysis/s4_meta.py` (정규식, LLM 없음) → `data/meta/doc_meta.csv`
- 입력: 2-2 로그(`s2_removed.csv`), 2-3 본문(`data/stage/s3/`), 2-1·2-3 표(`doc_survey.csv`, `s3_pages.csv`)
- 채우는 곳: `schema.sql`의 `document.review_no / valid_from / valid_to / info_base_date` (+ 새 필드 `effective_date`)

## 필드와 규칙

| 필드 | 출처 | 규칙 |
|---|---|---|
| review_no | 2-2에서 지운 심의필 줄 | `준법감시인 사전심사필 제2026-15499-1호` → `2026-15499-1` |
| valid_from / valid_to | 2-2에서 지운 유효기간 줄 | `(2026. 10. 16 ~ 2027. 10. 16)` |
| info_base_date | 본문 | ① `YYYY.MM.DD 현재` ② 이자율·금리 문맥의 `… 기준` ③ `이자율 (YYYY.MM.DD …` 괄호 안 날짜. 표기: `2026.10.16` / `2026.9.1` / `’26.08.14` / `2026년 8월 20일`. 앞 15자에 '예시'가 있으면 제외 |
| effective_date | 본문 (약관·특약 부칙) | `이 특약/약관은 YYYY.MM.DD부터 (개정/변경) 시행` 중 가장 늦은 날짜 |

## 기준일이 없는 상품설명서 19개 (원문에 없음 — 정상)
- 대출 설명서 10개: 금리가 빈칸 서식이라 기준일 없음
- 세이프지수연동예금(ELD) 5개: 금리 대신 모집기간·계약기간 날짜 (상품 고유 정보 → LLM 추출 대상)
- 골드바 2개(가격 고시), 퇴직연금 정기예금, 외화당좌예금(이자 없음), 청년 주택드림(OCR 대상)

## 검증
- 유효기간 시작 ≤ 끝: 전부 정상. 스냅샷(2026-11-06) 기준으로 이미 끝났거나 아직 시작 안 한 문서 0개
- 기준일 범위(2020 ~ 2026-11-06) 밖: 머니그램 특급송금 서비스 `2018-06-19` 1건 — 수수료표 원문 날짜 그대로 (오래된 정보로 표시 필요)
- 기준일이 유효기간 시작보다 60일 넘게 앞선 문서 2개(Npay biz 신한통장 2025-09-01, 생계비계좌 2026-02-02) — 원문 그대로, 답변에 기준일을 보여줘야 하는 이유
- 시행일이 없는 약관·특약 20개는 원문에 부칙 날짜가 없음 (적립식예금약관, 여신거래기본약관 등)
