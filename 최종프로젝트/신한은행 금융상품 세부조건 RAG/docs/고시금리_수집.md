## 수집 중 발견한 문제와 처리
1. **읽기 타이밍 문제**: 상품을 바꾼 직후(1.1초) 읽으면 표가 반쯤만 바뀌어 **앞 상품의 행이 섞임** (신용대출 첫 수집 130행 중 45행이 이전 상품 행, 부동산담보는 반대로 행이 빠짐) → **표 내용이 3번 연속 같을 때까지 기다린 뒤 읽기**로 바꿔 대출 전체 재수집
2. 예금은 같은 방식으로 다시 읽어 **상품별 체크섬 92/92 일치** → 처음 저장본 유지
3. 숨겨진 이전 표가 함께 읽히던 문제 → 화면에 보이는 표·행만 읽기
4. 페이지 보안정책(CSP) 때문에 브라우저 → 로컬 파일 전송 불가 → 브라우저에서 표를 정리해 받아 파일로 저장

## 쓰는 원칙 (답변)
- 숫자(금리)는 **고시 금리(as_of 날짜 표시)** 우선, 조건·규칙은 **설명서(출처 쪽 표시)**
- 대출 금리는 반드시 **"예시 금리 + 산출 가정"**과 함께 (예: "1억5천만원·12개월·신용 3등급 가정")
- 고시 금리와 설명서 금리가 다르면 날짜와 함께 둘 다 보여줌
- 갱신: 고시 금리는 매일 바뀔 수 있어 재수집 주기를 정해야 함 (수집 절차는 이 문서의 방법 그대로 반복)
