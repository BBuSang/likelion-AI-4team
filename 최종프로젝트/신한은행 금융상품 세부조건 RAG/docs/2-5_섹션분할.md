## 개선 1: 한 문서 안 같은 항목 반복 (2026-11-09)
- 문제: 같은 `section_path`가 한 문서에 두 번 이상 나오는 경우 106건 → 원인 분류
  - **A. 다른 행을 한 이름으로 묶음** (`거래제한` ← 이용제한 사항·거래중지·입금제한, `계약기간` ← 가입기간 등): 분할은 맞고 이름이 거침 → **섹션 이름은 원문 표기**, 사전의 대표 이름은 `label` 필드로 분리
  - **B1. 표 안의 열 이름을 행 이름으로 오인** (Npay biz 통장 `이자율` 행 안의 `기본이자율 / 우대이자율 / 최고 이자율` 열): 잘못된 분할 → 행 이름이 **내용 없이 바로 이어지면**: 3개 이상은 열 이름(모두 무시), 2개는 묶음 행 + 하위 행(앞의 것만 무시, 예: ELD `적용이율 → 모집기간이율`)
    - 처음엔 '2개 이상이면 모두 무시'로 했다가 ELD `모집기간이율`(내용 있음)까지 사라지는 부작용 발견 → 2개/3개 이상으로 나눔
  - **B2. ELD 요약표·상세표, 금은 '기준가격'**: 원문에 실제로 두 번 나옴 → 정상, 유지
  - **B3. 부칙 여러 개** (개정일별): 정상 → `부칙`, `부칙 (2)` … 번호

## 개선 4: 목차형·투자설명서·기타 규칙 (2026-11-09)
- 진행 순서: ① 규칙을 고치기 **전에** 새 검증 문서 3개 정답 표시(`section_gold_holdout3.json`: 목차형 D233, 투자설명서 D196, 기타 D085) ② 보완 측정 5개 문서(`holdout2`)를 dev로 삼아 규칙 수정 ③ 마지막에 3차 검증 세트 채점
- 정답 기준 통일: 처음 정답(표형 위주)은 내용 없이 이어지는 **서로 다른 제목도 모두 경계**로 표시했는데, 2·3차는 '첫 줄만 경계'로 표시해 기준이 달랐음 → 처음 기준으로 통일하고 2·3차에서 빼 두었던 줄을 기계적으로 다시 넣음 (3차는 채점 전에). dev 정답 누락 3건 보정(D235 '가.'·'(N)' 소제목·`[참고]` 표 제목, D229 154) — 모두 `_corrections`에 기록
- 규칙 (dev 근거, `--no-improve4`로 끌 수 있음)
  1. 문장 끝 판정 수정: `상품개요`·`공모개요`의 '요'를 문장 끝으로 보던 버그 → `해요·세요·어요·예요·네요`만 문장 끝 (이 때문에 간이투자설명서의 `1 / 상품개요`를 못 잡았음)
  2. 숫자만 있는 줄 + 제목: 다음 줄이 한글로 시작할 때만 (정산표 `15 / 38%` 제외), 두 단 배치로 섞인 번호(1·2·3·4·7·6·5·8)는 아직 안 나온 번호면 허용, `Ⅰ.`·`Ⅱ.`에서 번호 1부터 다시
  3. PDF 전용 기호(U+F000 등)로 시작하는 짧은 줄 = 큰 제목 (한 줄에 3번 이상 나오는 기호는 선택 칸이라 제외)
  4. 뒤에 붙은 약관의 `제N조〔…〕` = 큰 제목, 그 안의 `3. …` 번호 항목은 큰 제목 아님
  5. `별표1`, `[부록] …`·`[설명의무이행확인]` (문서에 한 번만 나오는 괄호 글) = 큰 제목
  6. 소제목: `가. 제목`, `(1) 제목`·`1) 제목`, `■·◉·◾·◆·☑·⋄·▶·￭·※ + 명사구` (문장이거나, 다음 줄이 같은 기호로 시작하는 목록 항목이면 제외)
  7. 용어 부록: 짧은 용어 줄 다음에 `•·▪·-` 설명 → 용어마다 섹션
  8. 같은 글자의 제목이 내용 없이 되풀이되면 뒤의 것 무시
