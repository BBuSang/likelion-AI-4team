## 3. 설명서에만 있는 정보 (직원 질문에 직결)

**KB맑은하늘적금** — API는 미션 이름과 %p만 있음
- 대중교통 미션 인정기준: 버스·지하철만 (택시·고속/시외버스·기차 제외), 본인 명의 KB국민 신용/체크카드만 (KB국민비씨·가족·기업·선불카드 제외), **티머니 계열 체크카드는 실적 불인정**
- 실적 기간과 판정: 신규월 1일 ~ 만기월 전전월 말일, 발생월수가 계약기간의 1/2 이상 (예시 포함)
- 대중교통 우대는 가입 시 '상품별 선택 개인(신용)정보 동의'를 해야만 적용, 가입 후 변경 불가
- 종이서식 미션 = 디지털창구·태블릿브랜치·비대면 가입, 퀴즈 = 전용화면 미세먼지 퀴즈 3문항 (전용화면 경로 안내)
- 모든 우대는 만기해지 계좌에만 적용
- 중도해지이율 표 (기간별 기본이율×50~90%×경과월수/계약월수, 최저 0.1~0.2)
- 월 1만~100만원, 비과세종합저축 가능, 일부인출·재예치·만기앞당김 불가, 담보대출 잔액 95%, 무료 보험(대중교통·자전거 상해)

**우리SUPER주거래적금** — API는 항목명과 %p만 있음
- 급여이체 인정기준: 지정 이체일에 50만원 이상, 또는 적요에 '급여·월급·급료·수당' 또는 등록 직장명 + 월 50만원 이상. **개인명의 계좌에서 온 돈은 제외**. 휴일이면 전후 영업일 인정
- 연금이체 = 국민·공무원·사학·군인·보훈연금
- 실적 인정기간 = 신규월 ~ 만기월 전전달
- 중도해지 시 우대 미적용, 중도해지이율 표 (최저 0.15%)
- 자유적립식 일부해지 3회 한도, 정액적립식 만기앞당김 조건 (적립회차 미충족 시 추가금리 불가)

**카카오뱅크 26주적금** — API가 이미 비교적 자세함
- 7주차까지 연속 성공하면 이후 실패해도 1.00%p 유지
- 자동이체는 10시·18시 처리, 잔액 부족 시 해당 주차 실패
- 긴급출금 최대 2회 + 출금 후 잔액 10만원 이상, 1인 최대 30계좌
- 중도해지금리 표 (기본×10~50%×경과일수/계약일수, 최저보장 0.1~0.5)

## 4. API에만 있는 것 / API가 나은 점
- 100개 상품이 같은 형식, 공시월·제출일시(`fin_co_subm_day`)로 최신성 확인
- 금리·기간·적립방식이 숫자/코드라 조건 필터에 바로 사용

## 5. 결론
- 설명서를 더할 가치가 큼: 직원이 실제로 묻는 "이 조건 인정되나요?"(카드 종류·이체 기준·중도해지 시 우대 여부)의 답이 설명서에만 있음.
- 구조 후보: **API = 정형 테이블(필터·금리·최신성)**, **설명서 = 항목 단위 텍스트 청크** (메타데이터: 상품코드·은행·문서종류·기준일·쪽). 상품코드로 두 쪽을 연결.
- 공통 약관(예금거래기본약관·적립식예금약관)은 상품 간 중복이 많아 우선순위 낮음. 상품별 특약은 설명서와 겹치지만 법적 원문이라 보조로 유지 검토.
- 표 깨짐 때문에 청킹은 쪽 단위가 아니라 **항목명(우대이율·중도해지이율·만기후이율…) 기준**이 필요.
