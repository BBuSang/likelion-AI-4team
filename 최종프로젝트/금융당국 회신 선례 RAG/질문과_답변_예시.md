# 질문과 답변 예시 (실제 실행 결과)

2026-11-10에 LLM 포함 RAG(KURE-v1 검색 → 상위 5개 묶음 → gpt-6-luna 답변)를 돌린 결과에서 뽑은 실제 질문과 답변이다. 글은 저장된 결과 파일(`data/eval/f4_answer_eval.json`)을 코드로 그대로 옮겼다. 평가 방법과 점수는 [질문_방식과_결과_표시.md](질문_방식과_결과_표시.md)와 [worklog.md](worklog.md) 65번을 본다.

**읽는 법**
- 질문은 실제 직원이 쓴 것이 아니라, 회신 원문을 보고 LLM(OpenAI)이 업무 말투로 만든 평가용 질문이다. 질문마다 정답 사례가 하나 정해져 있다.
- `[L2587]`처럼 대괄호 안은 근거 사례번호다. L은 법령해석, O는 비조치의견서다.
- 시점 표시: ⚠️ 회신일 이후 조문 개정·폐지, ✅ 이후 개정 없음, 🔶 규정 개정됨(조문 변경 미확인), 🕒 시행 예정 개정, ❔ 확인 불가. ⚠️는 회신이 무효라는 뜻이 아니라 "현재 적용 여부 확인 필요"라는 뜻이다.
- 시험 세트(test3, test4, final_test)의 문항은 한 번만 평가하는 절차를 이미 마친 뒤의 결과라 여기에 실었다. 이 문서를 보고 시스템을 고치지 않는다.
- 예시는 대표 사례를 골라 실었다. 전체 문항의 답변은 결과 파일에 있다. 아래 4부는 일부러 고른 실패·한계 사례다.
