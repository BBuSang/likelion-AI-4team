# 데이터 탐색(EDA): 금융당국 회신 선례 데이터

작성일 2026-11-10. 이 문서는 RAG를 만들기 전·중에 데이터가 어떻게 생겼는지 확인한 내용을 한곳에 모은 것이다. 분포 수치는 **현재 DB(`interp` 스키마)를 읽기 전용으로 조회해 계산**했고(생성 스크립트는 저장소 밖), 수집·전처리 단계에서 찾은 문제와 처리는 [worklog.md](worklog.md)의 번호로 출처를 달았다.

**EDA(탐색적 데이터 분석)** 는 모델이나 검색을 만들기 전에 데이터의 구조, 분포, 이상값, 반복을 살펴 설계 결정의 근거를 얻는 단계다. 정답을 내는 게 아니라 "무엇을 조심해야 하는가"를 찾는 작업이다.

## 1. 한눈에 보기

| 단계 | 건수 | 설명 |
|---|---|---|
| 수집한 회신 | 4,366 | 법령해석 2,611 + 비조치의견서 1,755 (2014년 이후, 포털 상세 페이지) |
| 검색 대상 | 4,263 | 법령해석 2,611 + 비조치 1,652. 103건은 반려·철회 등으로 제외 |
| 청크가 있는 사례 | 4,262 | 포털 첨부 오류가 의심되는 1건을 제외 |
| 같은 내용 묶음 | 4,201 | 평가의 정답 단위 |
| 청크(검색 단위) | 8,973 | 질의 카드, 판단 본문, 규제 정비 카드 |
| 인용 조문 | 9,907 | 인용된 법령 294종 |

핵심 발견 5가지

1. **비조치의견서의 절반 이상이 사실상 같은 문구다.** 2016년 규제 정비 건(제목만 다르고 회답이 거의 같음)이 비조치의 54%다. → 별도 유형(`rule_review_2016`)과 별도 검색 단위(규제 정비 카드)로 분리했다.
2. **본문이 짧고 칸이 비어 있는 사례가 많다.** 회답이 "이유 참조"뿐인 사례, 질의요지가 없는 사례가 있다. → 빈 칸·참조 문구는 청크로 만들지 않는다.
3. **같은 내용의 회신이 반복된다.** 연장 건, 같은 본문 사례. → 사례 묶음을 만들고 평가 정답을 묶음 단위로 정했다.
4. **포털이 준 분야 값을 믿을 수 없다.** 구체적 분야도 틀린 예가 많고 2023년부터는 대부분 비어 있다. → 인용 법령으로 분야를 추정해 점수 가산용으로만 쓴다.
5. **오래된 회신일수록 인용 조문이 이후 개정된 비율이 높다.** → 회신일 이후 개정 여부를 표시하는 시점 검증(③)을 필수 기능으로 넣었다.

## 8. 반복과 중복

- **같은 내용 묶음**: 검색 대상 4,263건이 4,201개 묶음이 되었고, 2건 이상 묶인 것은 47개(109건)다. same_body 44개, same_question 3개. 묶는 규칙은 구분이 같고 질의·회답·이유가 같을 때이며 연장 건은 묶지 않았다(기한이 달라 효력 기간이 다른 선례, worklog 33번).
- **같은 제목을 가진 사례**(공백과 "(연장)" 표기를 뺀 제목이 같은 사례): 비조치의견서 52개 제목에 걸쳐 133건, 법령해석 24개 제목에 걸쳐 58건. 비조치가 훨씬 많다. 시황·한시 조치가 반복·연장되기 때문이다.
- 제목에 "연장"이 든 사례: 법령해석 10건, 비조치의견서 50건.
- 질의요지가 완전히 같은 일반 회신 160건(61묶음)은 제목에 "연장"이 든 경우가 60건이다(worklog 21번).
- 이 반복 때문에 **평가에서 같은 주제의 다른 회신이 1위로 오면 오답으로 계산되는 문제**가 계속 나타났다(worklog 45번, 56번, 57번).

## 14. 한계

- 이 문서의 분포 수치는 현재 DB 기준이다. 전처리·판정 규칙을 바꾸면 수치가 달라진다(조문 9,907건 등).
- 일부 서술(분야 추정 정확도, 연도별 조문 개정 비율의 근사값, 칸 길이 변화)은 worklog 작성 시점의 값을 인용했고 이번에 다시 계산하지 않았다. 해당 문장에는 worklog 번호를 달았다.
- 그래프는 문자 막대로만 표현했다. 발표용 시각화는 따로 만들지 않았다.
- 분야 수기 판정, 조문 연결 대조는 표본(100~200건 규모)이고 판정자가 규칙 작성자와 같다.
- 2016 규제 정비 건과 일반 회신의 차이, 연장 건 효력 기간 같은 도메인 판단은 데이터에서 읽은 것이며 법률 자문이 아니다.
